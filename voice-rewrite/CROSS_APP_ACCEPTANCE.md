# VoiceRewrite 跨应用验收矩阵（2026-11-13）

> 目标：防止“问答弹窗”功能破坏“直接改写替换”。这是可执行的测试规范，**不是通过报告**。
>
> 约束：Windows 11 x64、Mouse5 hold、Qwen3-ASR 本地、LM Studio 本地；不能使用第三方真实用户内容。必须测试真实的目标控件，不能只凭 `routeTask` 单元测试宣告成功。

## 必须通过（P0）

| ID | 场景 | 输入/语音 | 期望 |
| --- | --- | --- | --- |
| W01 | 微信聊天输入框 | 选中“你好”→“翻译成英文” | 直接替换成英文，不弹解释卡 |
| W02 | 微信聊天输入框 | 选中一段文字→“简洁一点” | 直接替换，不意外发送消息 |
| W03 | VS Code 普通文本编辑器 | 选中一行→“改得更正式” | 只替换该行选区；未选区域不改变 |
| W04 | VS Code 编辑器 | 长时间等待 LLM 时切换文件/焦点 | 旧结果不得写入新文件或新位置 |
| W05 | Chrome/Edge ChatGPT contenteditable | 选中英文→“请写成中文” | 优先直接替换输入框文本，不弹翻译预览 |
| W06 | Chrome 普通 textarea | 选中文本→“润色” | 直接替换，原窗口不跳转 |
| W07 | Windows 记事本 | 选中句子→“改得简洁” | 直接替换，Ctrl+Z 能回退 |
| W08 | 浏览器只读文章 | 选中术语→“这是什么意思？” | 在鼠标旁显示解释；页面不改变 |
| W09 | 浏览器只读文章 | 选中整段→“总结这段话” | 弹窗摘要，绝不模拟 Ctrl+V |
| W10 | 任意输入框 | 两次快速操作，首次 LLM 慢返回 | 只有最新仍有效任务可以写入 |
| W11 | 任意输入框 | 操作过程中用户编辑/删除了原选区 | 不覆盖已变化的内容；保存结果用于手动复制 |
| W12 | 任意输入框 | 用户切换窗口后 LLM 返回 | 不往当前新窗口粘贴 |
| W13 | 弹窗 | 关闭按钮、右上角 X、Esc | 能关闭且不会让 Mouse5 失效 |
| W14 | 托盘 | 右键打开菜单、退出 | 菜单正常，进程退出后侧键恢复原功能 |

## 故障与隐私（P0/P1）

| ID | 场景 | 期望 |
| --- | --- | --- |
| F01 | 剪贴板原有图片/HTML/文件 | 操作后不丢失用户原格式；当前 v8 不支持，不得宣称通过 |
| F02 | 读取选区超时 | 快速非模态报错，不锁住鼠标钩子或托盘 |
| F03 | 正在复制选区时用户主动复制新内容 | 不用旧快照覆盖用户的新剪贴板 |
| F04 | 模型返回格式不合法或空结果 | 不自动替换，不输出空白卡片 |
| F05 | ASR 录音过短/静音/幻觉短语 | 不向 LLM 发送无意义编辑命令 |
| F06 | 目标应用以管理员权限运行 | 明确告知权限问题；不谎称写入成功 |
| F07 | 多屏幕/DPI 125%/150% | 卡片在可见区域、文本与按钮不重叠 |
| F08 | Explorer/taskbar 重启 | 托盘恢复、鼠标 hook 仍可用 |
| F09 | 误启第二个 VoiceRewrite | 不允许两个实例同时占用 Mouse5 |
| F10 | 旧请求取消后返回 | generation 不匹配的结果绝不可粘贴 |
| F11 | 原文字包含 prompt injection | 只作为待处理数据，不能执行所选文本中的系统命令 |
| F12 | 日志 | 只输出长度、时间、路由、错误码，不记录真实内容 |

## 证据字段

```
build=...
session_id=<random>
target_app=<category or generic process>
stage=selection ms=...
stage=asr ms=...
stage=llm ms=...
route=replace|try_replace|popup
paste_status=verified|unverified|failed|not_requested
clipboard_restore_status=restored|not_owned|unsupported|failed
```

此处是**目标日志格式**，不是当前 v8 已实现的字段。

## 通过标准

- P0 的 W01–W14 必须有**真实 Windows 桌面**验收记录，尤其是 W01/W03/W05 不能用 unit tests 替代。
- P0 故障测试不得导致错误窗口的文字被覆盖、丢失用户原剪贴板内容或 Mouse5 持续卡住。
- 可选场景失败应回退为显式、可复制的结果；不得把生成文本或弹出窗口成功当作已替换。
- 任一新功能 PR 都要包含对应的回归结果与构建编号。
