# VoiceRewrite v0.1.0

Voice dictation and AI-assisted text editing for Windows 11.

## Features

- **Voice dictation:** Hold the configured dictation shortcut to speak, then release to insert text at the cursor.
- **AI text actions:** Select text, hold the voice-command shortcut, and ask to rewrite, translate, explain, or summarize it. Editing results can replace the selection; other answers appear in a copyable result card.
- **Shortcut recording:** Assign keyboard combinations, function keys, or Mouse4/Mouse5 directly from Settings—no need to type shortcut names.
- **Native Windows interface:** Compact settings, recording status indicator, and AI result card.

## Improvements

- Faster feedback when recording begins, without blocking notification beeps.
- More reliable copying of selected text, with safer retries and clipboard preservation.

## Download

- **VoiceRewrite-Setup-0.1.0-x64.exe** — Windows installer.
- **VoiceRewrite-windows-x64.zip** — Portable version; unzip and run.

## Before you start

Configure your ASR (speech recognition) and LLM (text generation) endpoints in Settings. The local or remote AI services are not bundled with VoiceRewrite. The installer is currently unsigned, so Windows SmartScreen may show an unknown-publisher warning.
